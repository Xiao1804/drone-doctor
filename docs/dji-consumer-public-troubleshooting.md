# DJI 消费级排查流程草案

用途：把公开资料整理成产品可用的“初筛流程”。所有结论均需人工复核，尤其是飞控、动力、电池、碰撞后安全风险。

## 通用安全前置

1. 先问是否发生过碰撞、跌落、进水、电池鼓包/漏液。
2. 有以上任一情况，停止试飞，记录证据并建议送检。
3. 无明显安全风险时，再做非侵入式排查：App 提示、固件/App 版本、连接状态、电池状态、环境干扰、校准状态。
4. 不建议用户自行拆机、焊接、更换飞控/电调/电池芯。

## 无法起飞

来源：DJI-S05、DJI-S15、DJI-S18

1. 记录 App 提示码和机型。
2. 若无明确提示，先更新 DJI App 和飞机固件。
3. 查地图：是否处于 Restricted Zone/GEO 区域。
4. 关机检查螺旋桨：型号、方向、破损、弯曲、是否完全展开。
5. 启动电机观察是否四个电机都能正常转动。
6. 检查 Beginner/Tutorial mode 与 GPS 信号。
7. 任一电机异常、螺旋桨损伤或空域未授权，停止起飞。

## 云台卡住 40002

来源：DJI-S01

1. 关机，取下云台保护罩。
2. 展开机臂，移除 microSD 卡后再试。
3. 关机状态下检查云台周围异物，轻柔确认云台能否转动。
4. 清理异物后重启。
5. 无异物则执行云台校准。
6. 仍提示 40002 或转动异常，送检。

## IMU/指南针/GPS 异常

来源：DJI-S02、DJI-S03、DJI-S04

1. IMU：电量至少 50%，水平干燥表面，按 App 指示方向摆放。
2. 指南针：远离强磁场、大型金属、电气设备、停车场、船只和地下钢筋建筑。
3. GPS：开机后等待 1-3 分钟；室外开阔地起飞，避开楼群、树木、山体、高压线和基站。
4. 若进入 ATTI 或无法自动悬停/刹停，应尽快在安全地点降落。
5. 校准或换环境后仍异常，停止飞行并送检。

## 遥控断连、信号弱、图传黑屏

来源：DJI-S06、DJI-S07、DJI-S08、DJI-S15

1. 飞前确认飞机和遥控器兼容，均已开机，App 最新。
2. 更新飞机和遥控器固件；必要时重新对频。
3. 信号弱时调整天线方向，确保天线平面朝向飞机。
4. 图传异常时检查信道状态，优先使用 Auto，离开高干扰/高楼密集区域。
5. 取出 microSD 卡并重启测试；换兼容移动设备交叉验证。
6. 飞前设置 Signal Lost 为 RTH，并设置高于障碍物的返航高度。
7. 飞行中图传丢失但仍可控时，先保持可控、避障、按地图轨迹返航；不可控时按预设 RTH 等待。

## 电池无法充电或无法开机

来源：DJI-S09、DJI-S10

1. 查看电池外观：鼓包、漏液、破损、充电口异常立即停止使用。
2. 用单电池直充和充电管家交叉测试。
3. 更换可靠充电器和线缆。
4. 确认充电环境温度在来源建议范围内。
5. 新电池/久置电池先充电唤醒。
6. 开机方式：短按释放后立即长按约 2 秒。
7. 四灯同时闪烁、App 电池错误或仍无法开机，联系 DJI 支持。

## 起飞漂移或无法悬停

来源：DJI-S04、DJI-S11、DJI-S12、DJI-S13

1. 先排除碰撞、跌落、进水。
2. 看 App 自检：IMU、指南针、视觉系统、GPS 是否报错。
3. 换到开阔、纹理正常、非反光地面，等待 GPS 正常。
4. 按 App 指引做 IMU、指南针或视觉系统校准。
5. 若仍漂移、不能悬停或有碰撞历史，停止试飞并送检。

## 返航/飞丢

来源：DJI-S15、DJI-S16、DJI-S17

1. 飞前等待 Home Point 更新提示。
2. 设置 Signal Lost 为 RTH。
3. 返航高度高于周围障碍物。
4. 低电 RTH 提示出现后优先返航或安全降落，不建议取消后继续远飞。
5. 飞丢后优先人身安全，使用 Find My Drone 和飞行记录定位。
6. 找回后如有坠落、进水或未知外力，送检后再飞。
