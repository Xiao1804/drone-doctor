## 二、意见箱设计

### 2.1 设计原则

**低摩擦**：不要求登录，30秒内完成提交  
**分类明确**：让用户知道什么值得写  
**反馈闭环**：提交后有确认，后续有跟进  
**激励参与**：让写意见的人感到被重视

### 2.2 入口设计

**方案A：全局悬浮按钮**（推荐）

页面右下角固定一个"意见反馈"按钮，所有页面可见：

```
┌─────────────────────────────────────────┐
│                                         │
│         （页面内容）                      │
│                                         │
│                              ┌───────┐ │
│                              │ 💬 意见 │ │
│                              │   反馈  │ │
│                              └───────┘ │
└─────────────────────────────────────────┘
```

- 图标：💬 或 ✉️
- 文字：鼠标悬停显示"意见反馈"
- 位置：右下角，距底部80px（避开移动端操作区）
- 样式：圆角按钮，品牌蓝色，轻微阴影

**方案B：导航栏入口**

在顶部导航栏最右侧添加"意见反馈"链接，点击后展开侧边栏或跳转页面。

**推荐方案A**，因为：
- 全局可见，随时可触达
- 不占用导航栏空间
- 移动端友好

### 2.3 表单设计

点击按钮后，展开一个**侧边抽屉**（从右侧滑出）：

### 2.4 字段说明

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 反馈类型 | 单选（4个标签） | ✅ | 功能建议/Bug反馈/内容纠错/其他 |
| 详细描述 | 多行文本 | ✅ | 最少10字，最多500字 |
| 联系方式 | 单行文本 | ❌ | 微信号/手机号/邮箱，用于后续跟进 |
| 当前页面 | 自动记录 | - | 提交时自动记录用户在哪个页面 |

### 2.5 提交后反馈

**即时反馈**（提交成功后立即显示）：

```

│           ✅ 感谢你的反馈！               │

```

### 2.6 行为心理学设计

| 设计点 | 原理 | 实现 |
|---|---|---|
| **低门槛** | 认知负荷减少 | 不要求登录，3个字段，30秒完成 |
| **分类标签** | 选择题减少决策 | 4个预设标签，点击即选 |
| **社会认同** | 从众心理 | 底部显示"已收到328条反馈，采纳47条" |
| **即时正反馈** | 操作性条件反射 | 提交后立即显示感谢动画 |
| **承诺一致** | 渐进承诺 | 留下联系方式的用户更可能持续关注 |
| **互惠原则** | 回馈心理 | 我们认真对待你的意见，你也更愿意继续使用 |

### 2.7 后续跟进机制

**管理员后台**（可后续迭代）：
- 查看所有反馈列表
- 按类型筛选
- 标记状态：待处理/处理中/已采纳/已拒绝
- 对留联系方式的用户发送回复

**数据表设计**：

```sql
CREATE TABLE feedback (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  type TEXT NOT NULL,           -- 'feature' | 'bug' | 'content' | 'other'
  content TEXT NOT NULL,        -- 反馈内容
  contact TEXT,                 -- 联系方式（可为空）
  page TEXT,                    -- 提交时所在页面
  status TEXT DEFAULT 'pending', -- 'pending' | 'processing' | 'accepted' | 'rejected'
  admin_reply TEXT,             -- 管理员回复
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

### 3.2 渐进式内容解锁

**设计原则**：让用户先尝到甜头，再引导深度参与

**免费层**（无需登录）：
- 每篇文章的**前30%内容**完整展示
- 新手入门分类**全部免费**
- 故障排查分类的**摘要和第一步**免费

**登录层**（需登录）：
- 完整文章内容
- 学习进度保存
- 收藏功能

**会员层**（需付费）：
- 高级维修教程
- 配件渠道推荐
- 优先查看新内容

## 七、数据表设计

### 7.1 意见箱表

```sql
CREATE TABLE feedback (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  type TEXT NOT NULL,
  content TEXT NOT NULL,
  contact TEXT,
  page TEXT,
  status TEXT DEFAULT 'pending',
  admin_reply TEXT,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

### 7.2 知识库表

```sql
-- 文章表
CREATE TABLE articles (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  title TEXT NOT NULL,
  content TEXT NOT NULL,
  category TEXT NOT NULL,
  device_type TEXT,
  difficulty INTEGER DEFAULT 1,
  view_count INTEGER DEFAULT 0,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 用户阅读记录表
CREATE TABLE user_read_articles (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id TEXT NOT NULL,
  article_id INTEGER NOT NULL,
  read_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  UNIQUE(user_id, article_id)
);

-- 用户收藏表
CREATE TABLE user_favorites (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id TEXT NOT NULL,
  article_id INTEGER NOT NULL,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  UNIQUE(user_id, article_id)
);
```

### 7.3 CAAC题库表

```sql
-- 题目表
CREATE TABLE questions (
  id INTEGER PRIMARY KEY AUTOINCREMENT,

  user_id TEXT NOT NULL,
  question_id INTEGER NOT NULL,
  answer TEXT NOT NULL,
  correct BOOLEAN NOT NULL,
  time_spent INTEGER,
  answered_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE user_checkins (

  user_id TEXT NOT NULL,

);
```

## 九、总结

本次方案补充了三个模块：

1. **意见箱**：低摩擦反馈收集，全局悬浮按钮，30秒完成提交，即时反馈闭环
2. **知识库**：渐进式内容解锁，学习进度追踪，相关推荐，收藏功能
3. **CAAC考证**：题库练习+错题本+每日打卡+模拟考试，游戏化学习体验

**关键设计原则**：
- 所有功能都遵循"先体验价值，再引导注册/付费"
- 使用游戏化元素（打卡、徽章、进度条）提升参与度
- 提供即时反馈和正向激励

**建议实施顺序**：
1. P0：意见箱（1天）→ 快速收集用户反馈
2. P1：知识库文章页（2天）→ 补齐内容模块
3. P1：CAAC题库练习（2天）→ 补齐考证模块
4. P2：错题本+打卡（1天）→ 提升学习持续性
5. P3：模拟考试（2天）→ 高价值功能

**下一步**：
1. 准备知识库初始内容（至少20篇文章）
2. 准备CAAC题库初始数据（至少200道题）
3. 开发意见箱功能并上线
4. 根据意见箱反馈迭代其他功能
