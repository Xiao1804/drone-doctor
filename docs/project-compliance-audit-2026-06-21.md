# DroneDoctor 项目现状审计

**审计日期**：2026-06-22

**目标版本**：v1.3.0 需求验证版

**结论**：代码已切换为“微信引流 + 免费兑换券 + 匿名限时体验”路径，普通账号和付费会员不再出现在公开产品流程中。

## 已完成

- 公开注册接口返回 `410 PUBLIC_ACCOUNTS_RETIRED`；
- 普通历史账号不能登录，登录入口仅供管理员使用；
- 个人中心、历史记录和“我的反馈”页面已下线；
- 历史记录 API 已停止挂载；
- 兑换券无需绑定账号，可激活 3 天匿名体验通行证；
- 重复兑换采用数据库条件更新，避免同一券码并发重复使用；
- 每次使用通行证都会核验券状态和到期时间，管理员可撤销已激活通行证；
- 管理后台可区分生成、实际发放、激活、诊断开始、诊断完成和反馈；
- 反馈允许匿名提交，并可留下微信或手机号；
- PostgreSQL 迁移纳入生产启动流程，禁止危险的基线回滚；
- 健康检查会验证数据库连接并返回版本号；
- 请求日志包含请求标识，部署包、数据库备份、校验和与恢复流程已有文档；
- 当前运行数据文件不再纳入 Git 跟踪。

## 当前约束

- 管理员账号仍保留，这是生成兑换券、查看反馈和市场数据所必需的内部能力；
- 数据库仍保留历史用户表和部分兼容字段，本版本通过路由与鉴权下线公开账号能力，没有执行破坏性删表；
- GitHub 全部分支和 `v1.2.0` 标签已重写，普通分支与标签不再包含历史运行数据；
- GitHub PR 1—9 的只读引用仍保留旧对象；GitHub Support 工单 `#4501736` 已提交并等待处理；
- 生产管理员密码已在验证数据库备份后完成轮换，线上新密码登录验证通过；
- 本次没有执行线上部署；生产数据库仅执行了已备份、可验证的管理员凭据轮换；
- Docker 镜像已经实际构建，并完成前后端容器及 Nginx 代理链路验证。

## 发布前必做

1. 先备份生产数据库并验证备份可读取。
2. 设置 `APP_VERSION=v1.3.0`，使用版本包和 SHA-256 校验发布。
3. 执行数据库迁移后检查 `pgmigrations` 包含：
   - `1781913600000_initial_schema`
   - `1782000000000_trial_access_and_feedback`
4. 验证健康检查、管理员登录、发券、激活、诊断和反馈完整链路。
5. 发布后观察错误日志和兑换券指标，发现异常时先止血，再判断代码回滚或向前修复。

## 剩余风险事项

- GitHub Support 尚未确认 PR 只读引用和缓存清理完成；
- 其他本地克隆、下载包或分叉仓库不会因强制推送自动清除，需要协作者重新克隆；
- 应用版本只做了本地容器验证，尚未部署到生产环境；线上仅执行数据库备份与管理员凭据轮换。
