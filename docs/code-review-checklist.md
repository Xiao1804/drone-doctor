# 代码审查快速检查表

> 打印或复制到 PR 描述中使用

## 提交前自检

- [ ] 代码本地运行正常
- [ ] `npm run lint` 无 error
- [ ] 核心流程手动测试通过
- [ ] 无密码/密钥/Token 硬编码
- [ ] 前端 `npm run build` 成功

---

## 🔴 Blocker 必查项

### 安全
- [ ] 所有 SQL 使用参数化查询（`?` / `$1`）
- [ ] 用户输入经过校验（类型、长度、范围）
- [ ] 敏感接口有认证中间件
- [ ] 文件上传限制类型和大小
- [ ] 不暴露内部错误详情给客户端
- [ ] 日志中无敏感信息

### 正确性
- [ ] 核心功能回归测试通过
- [ ] 异步错误有 `try/catch` 或 `.catch()`
- [ ] Promise 不会裸奔（unhandled rejection）
- [ ] 数据库连接/事务正确使用

---

## 🟡 Suggestion 常规项

### 后端
- [ ] 错误使用 `AppError` + `errorHandler` 统一处理
- [ ] 路由参数有校验
- [ ] API 响应格式符合项目约定
- [ ] 复杂逻辑有注释说明
- [ ] 无重复代码（DRY）

### 前端
- [ ] `useEffect` 有清理函数（需要时）
- [ ] 列表有稳定 `key`
- [ ] 异步数据有三态处理（loading/empty/error）
- [ ] 网络请求有错误处理
- [ ] 组件职责单一

### 通用
- [ ] 命名清晰（函数/变量/文件）
- [ ] 新功能有对应测试或测试计划
- [ ] 复杂算法/业务规则有文档

---

## 💭 Nit 可选项

- [ ] 代码风格一致
- [ ] 注释拼写正确
- [ ] 删除无用代码/注释
- [ ] 优化导入顺序

---
