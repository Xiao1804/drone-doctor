### 9.2 成本估算

**单次诊断成本**
- AI调用成本：约0.01-0.05元/次（GPT-4o-mini）
- 服务器成本：约0.001元/次
- 总成本：约0.02-0.06元/次

**用户使用频率**
- 免费用户：每日3次 = 90次/月
- 付费用户：假设每日10次 = 300次/月

**成本计算**
- 免费用户成本：90次 × 0.04元 = 3.6元/月
- 付费用户成本：300次 × 0.04元 = 12元/月

- 价格远低于培训费用

**核心卖点**
1. 快速定位问题（不用到处查资料）
2. 系统学习维修知识（提升技能）
3. 了解考证流程（准备考试）

**文案风格**
- 专业但不晦涩
- 实用导向（直接解决问题）
- 避免AI味（空泛、模板化）

**关键页面**
- 首页Hero区：标题、副标题、CTA
- How It Works：3步说明
- 场景卡片：3个典型场景
- 功能区：4个核心功能
- 定价区：3个套餐
- FAQ：4-6个常见问题

**禁词**
- 不要用"AI-powered platform"等空话
- 不要用模糊形容词（"强大的"、"智能的"）
- 不要用未经证实的承诺

### 11.2 给设计的摘要

**产品定位**
- 无人机健康诊断平台
- 工具型网站，不是内容型网站
- Hero区必须内嵌诊断工具入口

**核心页面**
- 首页：Hero区（诊断工具入口）+ How It Works + 场景卡片 + 功能区 + 定价区 + FAQ
- 诊断页：故障现象 + 排查步骤 + 所需工具 + 操作方法
- 知识库页：故障分类 + 维修教程 + 配件信息
- 考证页：考证流程 + 考试大纲 + 题库

**设计风格**
- 专业、简洁、实用
- 主色调：蓝色（科技感）+ 橙色（行动感）
- 移动端优先
- CTA持续可见

**关键要求**
- Hero区必须有内嵌工具入口（用户打开就能用）
- 诊断结果页面清晰展示排查步骤
- 定价区对比清晰
- 移动端适配

**反AI味约束**
- 不要只有渐变卡片
- 不要模板化布局
- 要有真实产品状态（不是占位符）

### 11.3 给开发的摘要

**技术栈**
- 前端：Next.js + React + Tailwind CSS
- 后端：Next.js API Routes / Cloudflare Workers
- 数据库：Cloudflare D1 / Supabase
- AI：OpenAI API / Anthropic API
- 支付：Stripe / 国内支付（支付宝/微信）

**核心功能**
1. AI故障诊断
   - 用户输入故障现象（文本/选择）
   - 调用AI API生成排查步骤
   - 返回结构化结果（步骤、工具、方法）

2. 用户系统
   - 免费用户：每日3次诊断
   - 付费用户：无限诊断
   - 使用次数限制（原子化扣减）

3. 支付系统
   - Stripe Checkout
   - Webhook验签
   - 订阅管理

**数据库设计**
- users表：用户信息、订阅状态、使用次数
- diagnoses表：诊断记录
- knowledge表：知识库内容

**API设计**
- POST /api/diagnose：诊断接口
- POST /api/checkout：支付接口
- GET /api/user：用户信息接口

**安全要求**
- API Key放在环境变量
- JWT_SECRET放在环境变量
- 支付Webhook必须验签
- 使用次数必须原子化扣减

**部署**
- Cloudflare Workers / Vercel
- 域名绑定
- HTTPS
- ICP备案（国内必须）

## 十二、风险与应对

### 12.1 技术风险

| 风险 | 应对措施 |
|---|---|
| AI诊断准确性不足 | 1. 建立专业知识库<br>2. 人工审核典型案例<br>3. 用户反馈机制 |
| 飞行日志解析技术复杂 | 1. 第一版不做<br>2. 后续版本逐步实现 |
| AI调用成本超预期 | 1. 使用更便宜的模型（GPT-4o-mini）<br>2. 限制免费用户次数<br>3. 优化Prompt |

### 12.2 市场风险

| 风险 | 应对措施 |
|---|---|
| 市场规模不足 | 1. 验证搜索量<br>2. 快速MVP测试<br>3. 30天Kill/Iterate/Scale决策 |
| 用户不愿意付费 | 1. 提供足够价值<br>2. 价格锚点（对比培训费用）<br>3. 免费层引流 |
| 竞品进入 | 1. 建立数据壁垒（知识库、用户评价）<br>2. 快速迭代<br>3. 专注细分市场 |

### 12.3 合规风险

| 风险 | 应对措施 |
|---|---|
| ICP备案 | 1. 准备备案材料<br>2. 选择可靠服务商 |
| 内容合规 | 1. 不发布违规内容<br>2. 用户生成内容审核 |
| 支付合规 | 1. 使用正规支付通道<br>2. 遵守外汇管理规定 |
