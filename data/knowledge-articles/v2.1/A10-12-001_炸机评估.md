## 现象描述

发生炸机、摔机、碰撞，需要评估损坏情况。

## 炸机后第一步

1. 立即关闭电源，取下电池
2. 确保飞行器在安全位置
3. 不要立即尝试再次飞行
4. 先进行全面检查

## 检查清单

### 1. 外观检查
- [ ] 检查机身是否有明显变形
- [ ] 检查机臂是否有损坏或断裂
- [ ] 检查云台是否有损坏
- [ ] 检查相机是否有损坏
- [ ] 检查电池仓是否有损坏
- [ ] 检查外壳是否有裂纹

### 2. 螺旋桨检查
- [ ] 检查每个螺旋桨是否有损坏
- [ ] 检查螺旋桨是否有变形
- [ ] 更换所有损坏的螺旋桨
- [ ] 确认螺旋桨安装正确

### 3. 电机检查
- [ ] 手动转动每个电机，检查是否顺畅
- [ ] 检查电机是否有异响
- [ ] 检查电机是否有松动
- [ ] 检查电机轴是否有弯曲

### 4. 电池检查
- [ ] 检查电池外观是否有损坏
- [ ] 检查电池是否有鼓包
- [ ] 检查电池触点是否清洁
- [ ] 如电池有损坏，不要使用

### 5. 云台检查
- [ ] 检查云台是否能正常转动
- [ ] 检查云台是否有卡顿
- [ ] 检查相机是否能正常工作
- [ ] 检查云台排线是否有损坏

### 6. 上电检查（在检查前项后）
- [ ] 安装电池，开启飞行器
- [ ] 检查飞行器是否能正常启动
- [ ] 检查云台是否能正常自检
- [ ] 检查图传是否正常
- [ ] 检查 GPS 是否能正常搜星
- [ ] 检查 IMU 是否正常

### 7. 测试飞行（在安全环境）
- [ ] 选择开阔无人场地
- [ ] 先进行悬停测试
- [ ] 观察是否有异常震动
- [ ] 测试各方向飞行
- [ ] 测试云台和相机
- [ ] 确认一切正常后再正常飞行

## 何时建议送修

- 机臂有明显断裂或严重变形
- 云台损坏严重
- 电机有明显损坏
- 机身有严重变形
- 上电后有异常报错
- 测试飞行有明显异常
- 新手用户，不确定损坏程度
- 在保内的机器

## 炸机后的处理流程

```
1. 立即断电 → 2. 外观检查 → 3. 更换损坏部件 → 
4. 上电检查 → 5. 测试飞行 → 6. 正常使用 / 送修
```

## 预防建议

1. 不要在视线外飞行
2. 不要在障碍物附近飞行
3. 注意飞行环境
4. 保持飞行器在视线内
5. 低电量时立即返航
6. 大风天气不要飞行
