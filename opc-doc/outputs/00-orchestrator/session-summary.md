# DroneDoctor OPC 建盘流程 - 会话摘要

## 项目信息
- **项目名称**: DroneDoctor - 无人机AI诊断平台
- **当前阶段**: 01 资源盘点
- **启动时间**: 2026-05-29
- **用户模式**: 引导模式（边走边解释术语）

## 项目背景（已确认）
DroneDoctor 是一个面向国内无人机用户的AI故障诊断与维修知识平台：
- 核心功能：AI故障诊断、维修知识库、CAAC考证指南
- 商业模式：Freemium订阅（免费版每日3次 / 月度39元 / 年度299元）
- 技术栈：React 18 + Node/Express + PostgreSQL/pgvector + Kimi/百度AI
- 部署：Vercel + Railway
- 状态：MVP开发完成，待测试上线
- AI工程方案：三阶段升级（语义检索 → 图像诊断 → 故障预测）
