# 无人机维修助手 — 前端设计要求

## 1. 整体视觉风格定位

网站需呈现**专业、精密、可信赖**的科技产品形象。整体美学应参考高端消费电子品牌（如 Apple、DJI 官网）与顶级 SaaS 产品（如 Linear、Vercel）的结合体。

核心关键词：**深空暗夜蓝**、**极光青柠绿**、**极简主义**、**未来科技感**。

页面需通过深邃的暗色调营造出一种“沉浸式控制中心”的氛围，让用户感受到产品的智能与高效。所有设计元素都应服务于信息的高效传达，避免任何无意义的装饰。

---

## 2. 配色方案 (Color Palette)

### 2.1 主色调
*   **背景色 (Background):** `#03045E` (深空暗夜蓝) — 用于全站主背景，营造深邃、专业的空间感。
*   **主强调色 (Primary Accent):** `#CCFF00` (极光青柠绿) — 用于核心行动按钮 (CTA)、关键数据高亮、重要状态指示。此颜色具有高视觉张力，在深色背景上极为醒目。
*   **次强调色 (Secondary Accent):** `#4361EE` (科技靛蓝) — 用于辅助信息、链接、次级按钮，以及部分数据可视化的渐变过渡。

### 2.2 文字与界面色彩
*   **主标题/重要文本:** `#FFFFFF` (纯白) — 确保在深色背景上的绝对清晰度和可读性。
*   **正文/辅助文本:** `#A0AAB2` (科技灰) — 降低视觉疲劳，区分信息层级。
*   **组件表面色 (Surface):** `#0A0F2C` (深蓝灰) — 用于卡片、导航栏、侧边栏等 UI 组件的背景，与主背景形成微妙的层次对比。
*   **分割线/边框:** `#1A2040` (暗蓝灰) — 用于划分内容区域，保持界面的整洁与秩序。

---

## 3. 排版与字体 (Typography)

### 3.1 字体选择
*   **主字体 (标题与正文):** `Inter` 或 `SF Pro Display`。无衬线字体，具有极佳的屏幕阅读体验和现代科技感。
*   **等宽字体 (数据与代码):** `JetBrains Mono` 或 `Fira Code`。用于显示无人机型号、故障代码、数据指标等，强化技术的专业感。

### 3.2 排版规范
*   **Hero 区主标题:** 64px - 80px, Font Weight 700, Letter Spacing -2px。需具有强烈的视觉冲击力，可采用渐变或描边效果。
*   **页面板块标题 (H2):** 36px - 48px, Font Weight 600, Letter Spacing -1px。
*   **正文 (Body):** 16px - 18px, Font Weight 400, Line Height 1.6。确保长文本的舒适阅读。
*   **数据指标 (Data):** 32px - 48px, Font Weight 700, 使用等宽字体。数字变化时应有平滑的滚动动画。

---

## 4. 布局与结构 (Layout & Structure)

### 4.1 网格系统
*   采用 **12 栏网格系统** (12-column grid)，页面最大宽度限制在 `1440px`，两侧保留充足的留白（至少 `24px` 在移动端，`48px` 在桌面端）。
*   强调**非对称布局**和**错落式排版 (Broken Grids)**，打破传统 SaaS 界面的呆板，增加页面的动感与设计感。

### 4.2 核心组件样式
*   **卡片 (Cards):** 采用 `#0A0F2C` 背景，边框为 `1px solid #1A2040`，圆角 `12px` 或 `16px`。hover 时边框可微弱发光或颜色渐变。
*   **按钮 (Buttons):** 
    *   **主按钮:** 背景 `#CCFF00`，文字 `#03045E`，圆角 `8px`，Font Weight 600。Hover 时增加光晕效果 (`box-shadow: 0 0 20px rgba(204, 255, 0, 0.4)`)。
    *   **幽灵按钮:** 透明背景，边框 `1px solid #4361EE`，文字 `#4361EE`。Hover 时背景填充为 `#4361EE`，文字变为白色。
*   **输入框 (Inputs):** 深色背景 `#0A0F2C`，底部或全边框 `1px solid #1A2040`，聚焦 (Focus) 时边框变为 `#CCFF00` 并带有微光提示。

---

## 5. 动画与交互 (Animation & Interaction)

### 5.1 滚动动画 (Scroll-triggered Animations)
*   **视差滚动 (Parallax Scrolling):** 背景图层与前景内容以不同速率移动，创造空间纵深感。
*   **渐显动画 (Fade-in & Slide-up):** 元素在进入视口时，以 `translateY(30px)` 配合 `opacity: 0 -> 1` 的方式优雅出现。动画时长建议在 `0.6s - 0.8s`，缓动函数使用 `cubic-bezier(0.25, 1, 0.5, 1)`。
*   **进度条/数据加载:** 页面滚动时，顶部可设置极细的极光青柠绿进度条。

### 5.2 微交互 (Micro-interactions)
*   **悬停效果 (Hover Effects):** 所有可点击元素（按钮、链接、卡片）在鼠标悬停时必须有即时反馈。例如：卡片轻微上浮 (`transform: translateY(-4px)`) 并增强阴影；链接文字下方出现下划线动画。
*   **磁性按钮 (Magnetic Buttons):** 核心 CTA 按钮可加入磁性吸附效果，鼠标靠近时按钮轻微向光标方向移动，增加趣味性。
*   **故障艺术 (Glitch Effect):** 针对“维修”这一主题，可在特定元素（如故障代码展示、图片切换）上加入轻微的、可控的故障艺术动效，强化科技感与产品属性。

### 5.3 3D 与特效
*   **3D 元素展示:** 若条件允许，首页 Hero 区应使用 WebGL 渲染的 3D 无人机模型，支持用户鼠标拖拽 360 度查看，或随鼠标移动产生视差倾斜。
*   **粒子系统/光效:** 背景可点缀极微弱的粒子流动或类似电路板的微光线条，模拟数据流动感，但需注意不能干扰主体内容的阅读。

---

## 6. 响应式设计 (Responsive Design)

*   **桌面端 (Desktop > 1024px):** 完整展示多栏布局、侧边导航、3D 特效。
*   **平板端 (Tablet 768px - 1024px):** 布局调整为 2 栏，侧边导航收拢为顶部导航，字号等比例缩小。
*   **移动端 (Mobile < 768px):** 单列布局，核心信息优先展示。3D 模型可替换为高质量静态图或简化的交互模型。所有按钮需适配拇指操作区域（最小 `44x44px`）。

---

## 7. 情绪板参考 (Moodboard References)

*   **整体氛围:** DJI 官网的简洁大气、Linear.app 的深色专业感、Stripe 的开发者友好界面。
*   **色彩运用:** 类似于电影《创：战纪》(Tron) 中的霓虹光感与深色背景的结合。
*   **动效风格:** Apple 产品页的丝滑滚动与优雅过渡。

---

**总结:** 本设计要求旨在通过深色科技美学、精准的数据可视化、以及丝滑的交互体验，塑造一款在视觉上领先于传统工业软件的现代化无人机维修助手。设计必须在“科技感”与“实用性”之间找到完美平衡，让维修人员在使用过程中感受到高效与愉悦。
